# VA_PISI

# O Projeto consiste em criar um sistema voltado para a gestão técnica e operacional de Drinks e Coquetéis.

## Funcionalidades
  # release 1.0
- **Catálogo Centralizado:** Visualização de todos os drinks e fichas técnicas em ordem alfabética.
- **Sistema de Busca Inteligente:** Encontra coquetéis pelo nome ou pesquisando por ingredientes específicos.
- **CRUD Completo:** Adição, edição ou exclusão de novos drinks e ingredientes.
  
  # release 2.0
- **Gestão Financeira:** Suporte para cálculos de custo e teor alcoólico das receitas cadastradas.
- **Estoque Inteligente:** Cruzamento de dados entre os ingredientes necessários e o que está disponível.
- **Interface:** Mudança de CLI (linha de comando) para um ambiente visual mais amigável e intuitivo, focado na facilidade de navegação.
